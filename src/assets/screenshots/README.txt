PUT PROJECT SCREENSHOTS IN THIS FOLDER
======================================

Two options per project (any of .png .jpg .jpeg .webp works):
  1. One image:  cineflix.png
  2. A gallery:  a folder named after the project, e.g. cineflix\01.png, 02.png ...
     Images show in name order; the first is the card cover. Name a file
     00.png or cover.png to use it only as the cover.
Clicking a project opens a popup with all its screenshots.
Already done: muhafiz, luxurystay, talktotext, multivox, laptop-harbour.
The site picks them up automatically - no code changes needed.

TIPS
- Take desktop screenshots at about 1440px wide (browser window maximised).
  For full-page captures, use "Capture full size screenshot" in Chrome
  DevTools (Ctrl+Shift+P) or the GoFullPage extension.
- Hide personal data, test emails and lorem ipsum before capturing.
- Keep each file under ~1 MB (squoosh.app can shrink them).
- After adding files, restart "npm run dev" if it's running.
